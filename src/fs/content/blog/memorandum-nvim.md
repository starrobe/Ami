## 快捷键

| 操作                        | 描述   |
| :---:                       | :---   |
| `<C-f>`                     | 下一页 |
| `<C-b>`                     | 上一页 |
| `{n}G`                      | 跳转到第n行  |
| `:jumps`                    | 查看跳转列表 |
| `:marks`                    | 查看标记列表 |
| `m{a~z}`                    | 标记光标当前位置，标记名为`{a~z}` |
| `m{A~Z}`                    | 跨缓冲区标记 |
| `` `{a~Z}``                 | 移动到标记位置 |
| `'{a~Z}`                    | 移动到标记行首 |
| `:s/{old}/{new}`            | 替换当前行的第一个`{old}`为`{new}` |
| `:s/{old}/{new}/g`          | 替换当前行的所有 |
| `:s/{old}/{new}/gc`         | 请求确认 |
| `:{n1},{n2}s/{old}/{new}/g` | 从`{n1}`到`{n2}`行 |
| `:%s/{old}/{new}/g`         | 从第一行到最后一行 |
| `*`                         | 向下搜光标下的单词 |
| `#`                         | 向上搜光标下的单词 |
| `<C-]>`                     | tag跳转|
| `<C-t>`                     | 沿着CTRL+]回退|

## 实用功能

### 读写文件

> 取自nvim tutor的Lesson 5.3与5.4

选择需要写入到新文件的内容，按`:`后会显示

    :'<,'>

然后输入`w { filename }`将选择的内容保存到另一个文件中，就像这样

    :'<,'>w TEST

NOTE: 这里写入的是一个新文件，如果已经存在该文件，会显示

    E13: File exists (add ! to override)

同时，也可将另一文件的内容写入到当前文件

    :r { filename }

NOTE: 也可输入命令

    :r !ls

### CTRL+R

现在的<ctrl-r>和<ctrl-r><ctrl-r>的行为一样了。

```
:let @a = "Line 1\rLine 2\x1b[ BOLD ]"
```

旧版本的<c-r>会得到，并回到Normal模式。

```
Line 1
Line 2
```

而<c-r><c-r>会得到

```
Line 1^MLine 2^[[ BOLD ]
```

新版本都会将内容视为普通文本进行原样插入。如果想得到之前<c-r>的效果可以用=

```
<c-r>=@a
```
